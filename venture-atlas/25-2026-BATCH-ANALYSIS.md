# 25 — 2026 YC Batch Analysis

## Scope

This is a **current portfolio snapshot**, not a complete census. YC's directory is a live dataset and its public category tags overlap, so the analysis avoids adding categories as if they were mutually exclusive.

## Winter 2026

Current directory examples include CellType (agentic drug discovery), Beacon Health (AI employees for primary care), Axis (AI-native commodity trading), Grade (performance-based payroll), Copperlane (mortgage underwriting) and Verdex (AI insurance adjustment).

### Observation
The common structure is not simply “AI startup.” It is **AI applied to expensive, specialized workflows**.

## Spring 2026

Current directory examples include Cerenovus (company knowledge/system mapping), Shiraz AI (robots learning tasks from demonstrations), Waddle Labs (robotics/developer tools), Grip (robotic waste sorting), OpenVector (AI vision on existing cameras), Atlia (AI-native property management) and Maingen (RL environments for industrial operations).

### Observation
Physical AI and industrial workflows appear unusually visible alongside enterprise AI.

## Fall 2026

The public directory already contains companies such as GodHands (engineering knowledge), twentyfour26 (autonomous CNC cells) and other F2026 companies, but the cohort itself is scheduled to run October–December 2026. Therefore any “Fall 2026 thesis” is provisional.

## 2026 pattern

```text
Foundation models
      ↓
Agents / multimodal systems
      ↓
Workflow automation
      ↓
Industry-specific execution
      ↓
Real-world data / feedback
      ↓
Defensibility
```

## What changed from the older YC model?

Not the core founder thesis. The **technical substrate changed**.

YC's historical preference for builders and large outcomes is still compatible with the current AI/robotics wave. The current cohort simply has more technical leverage available to founders.

## Falsifiability

The 2026 pattern should be retested after the full Fall 2026 batch is published and category tags are normalized.
